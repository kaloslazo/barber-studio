# Diapositivas de la exposición final

Diapositivas en Beamer (LaTeX), en formato 16:9. `main.pdf` es la versión compilada.

## Compilar

```bash
cd slides
pdflatex main.tex
pdflatex main.tex
```

## Orden

Son 20 láminas: problema, qué hace Fresh, arquitectura, qué es propio, Delaunay, barba, tinte, cortes, combinación y ficha, forma de cara, física, gaussianas 2D, espejo 3D, peluca 3D, Contrarreloj, calidad y rendimiento, límites y demo. La demo sigue `docs/demo_script.md`.

Las figuras están en `figures/`. Son las mismas del informe, más la malla de Delaunay (`malla.jpg`).
