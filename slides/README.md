# Diapositivas de la exposición final

Diapositivas en Beamer (LaTeX), en formato 16:9. `main.pdf` es la versión compilada.

## Compilar

```bash
cd slides
pdflatex main.tex
pdflatex main.tex
```

## Orden

Son 33 láminas: problema, qué hace Fresh, arquitectura, qué es propio, pipeline, temas del curso, Delaunay, barba, tinte, cortes, combinación y ficha, forma de cara, física, gaussianas 2D, espejo 3D, peluca 3D, Contrarreloj, Fiesta (proceso, cambio de cara, caricatura y fusión), calidad y rendimiento, límites y demo. Cada herramienta tiene una lámina con su diagrama de proceso. La demo sigue `docs/demo_script.md`.

Las figuras están en `figures/`. Son las mismas del informe, incluidas las de Fiesta (`fiesta_*.jpg`, `diagrama_fiesta.pdf`).
